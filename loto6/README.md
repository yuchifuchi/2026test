# ロト6 出現回数分析

過去の当せん番号を集計し、本数字(1〜43)の出現回数順から購入番号を組み立てるスクリプト。

```
python3 loto6/analyze_loto6.py          # report.md を再生成して標準出力にも表示
```

生成結果は [report.md](report.md)。

## 出力する2つの枠

| 枠 | 口数 | 作り方 |
|---|---:|---|
| ホット枠 | 10口 | 出現回数の**多い順**に並べた上位20個を、6個ずつ循環させて切り出す。上位20個が各3回ずつ均等に登場する(10 x 6 = 60 = 20 x 3)。 |
| 逆張り枠 | 3口 | 出現回数の**少ない順**に並べた下位18個を、先頭から6個ずつ切り出す。18個が各1回ずつ登場する。 |

同じ出現回数で並びが決まらない場合は番号の小さい順で安定させている。

## データ

`data/loto6_draws.csv` — 第1回(2000-10-05)〜第1197回(2017-08-03)、1197回分。

| 列 | 内容 |
|---|---|
| `draw` | 抽せん回 |
| `date` | 抽せん日 (YYYY-MM-DD) |
| `n1`〜`n6` | 本数字(昇順) |
| `bonus` | ボーナス数字(集計には未使用) |

出典: [Rosyuku/loto6](https://github.com/Rosyuku/loto6) の `loto6.csv`(みずほ銀行の公表結果をスクレイピングしたもの)を
UTF-8・列名英字に整形したもの。読み込み時に本数字の重複と 1〜43 の範囲を検証している。

### データが2017年8月までである理由

本セッションのネットワークは egress ポリシーで GitHub とパッケージレジストリ以外への接続が遮断されており、
みずほ銀行(`www.mizuhobank.co.jp`)や各ロト系CSV配布サイトはすべて 403 で到達できなかった。
そのため GitHub 上から取得できる最大のデータセットを使っている。

### 最新データへの更新手順

`data/loto6_draws.csv` を同じ列構成のまま新しい抽せん結果まで差し替えて、`analyze_loto6.py` を再実行するだけでよい。
みずほ銀行の「過去の当せん番号」CSV を使う場合は、本数字6列とボーナス数字1列を上記の列名に合わせる。

## 注意

ロト6の抽せんは毎回独立で、過去の出現回数は次回の当せん確率を変えない。
実際、1197回分の出現回数に対するカイ二乗検定は χ²=24.5(自由度42, p=0.99)で、
ばらつきはランダムな揺らぎの範囲に完全に収まっている。
この番号表は「出現回数順に機械的に並べた結果」であって、当たりやすさの根拠ではない。
