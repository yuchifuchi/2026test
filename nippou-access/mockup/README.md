# Web 版モックアップ

`nippou-mockup.html` は、ASP 版の画面を評価するための**動くモックアップ**です。
ブラウザで開くだけで動きます（サーバー不要）。

公開先: https://claude.ai/code/artifact/46df2775-819d-479e-8ff3-4b0f7f4730ab

## 触って確かめられること

| 操作 | 確かめられること |
|---|---|
| 受付入力で件数を足す | 上部の帯の「日報」と「集計表」が**同時に同じ数だけ動く**。経路が 1 本しかないことの実演 |
| 日報の件数欄を直そうとする | 直せない（自動集計のみ）。現行 Excel との決定的な違い |
| マスタ保守で誰かに退職日を入れる | 受付入力の担当者リストから消える。過去データは変わらない |
| 帳票プレビュー | 現行「印刷用」シートと同じ体裁。画面は角ゴシック、紙は明朝 |
| 集計表で「先週」を押す | 8/17〜8/21 の実データが出る |

## データについて

すべて現行 Excel の実データです。

- 製品 34 種・区分 57 種・担当者 18 名 ―― 記入用フォームの外部リンクキャッシュと `Sheet2`
- 受付記録 306 件 ―― `集計表（ＶＢＡ版）.xlsm` の 8/17〜8/25

数値は `tools/verify_migration.py` の検算結果と一致します
（8/24 = 128 件、8/25 = 119 件）。

保存はされません。ページを再読み込みすると初期状態に戻ります。

## 作り直す

```bash
python3 tools/gen_mockup_data.py <xlsm を置いたフォルダ> > mockup/data.json
# head.html + body.html + data.json + app.js を連結して nippou-mockup.html を作る
```
