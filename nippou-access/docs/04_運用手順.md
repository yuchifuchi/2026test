# 運用手順

## 毎日の流れ

現行との一番の違いは、**「転記」という操作が無い**ことです。
入力した瞬間にデータベースに入り、日報にも集計表にも同時に反映されます。

### ① パート職員 ― 受付を入力する

1. メニュー →「本日の受付を入力する」
2. **対象日**（既定は今日）と**自分の名前**を選ぶ
3. 明細に、区分・製品・件数を入れていく

- 製品を伴わない区分（顧客情報・イベント関係など）は
  製品欄を「（製品指定なし）」のままにする
- 同じ区分・製品の行が既にある場合は、その行の件数を直す
- 電話応対以外の業務は「電話応対以外の業務」ボタンから

担当者を選んだ時点で、その人はその日の**出勤者として自動登録**されます。
「入力したのに集計に出てこない」が起きない作りです。

### ② 職員 ― 日報を作る

1. メニュー →「日報を作成・確認する」
2. **出勤者**を確認（「在籍者を一括登録」→ 休みの人を外す、が速い）
3. **回線数**を入れる
4. **特記事項・職員に代わった案件・要望**を入れる
5. 「保存する」

問合せ件数の欄は受付入力から自動で計算されます。**手では直せません。**
これが現行 Excel との決定的な違いで、日報と集計表がずれる余地を無くしています。

### ③ 確定して印刷する

1. 日報画面の「確定する」
   - 出勤登録があるのに実績が 1 件も無い人がいると警告が出ます
   - 心当たりが無ければ「入力もれチェック」で確認してから確定
2. 「印刷」→ プレビュー → 印刷

### ④ 集計表を見る

メニュー →「集計表を見る／印刷する」→ 期間を指定（「今週」ボタンで月〜金）

**日報と数値が合わないことはありません。** 同じ `T_受電` から集計しているので、
突き合わせの作業自体が不要になります。

## 担当者の入退職

職員の入れ替わりが多いので、ここだけは手順を守ってください。

### 入職したとき

メニュー →「担当者マスタ」→ 一番下の空行に入力

| 項目 | 入れ方 |
|---|---|
| 担当者コード | 席番号（`019` など）。**過去に使ったコードを再利用してよい** |
| 姓・名 | 漢字。異体字（髙・﨑 など）もそのまま入れてよい |
| 職員区分 | パート または 職員。**帳票の「（）内は職員受電数」がこれで決まる** |
| 在籍開始日 | 初出勤日 |
| 表示順 | 一覧・帳票の並び順 |

### 退職したとき

**行は絶対に消さないでください。** `在籍終了日` に最終出勤日を入れます。

- 翌日から入力画面の候補に出なくなります
- **過去の日報・集計表はその人の名前のまま残ります**

行を消すと、過去の帳票からその人の名前が失われ、参照整合性のエラーになります。

### 復帰したとき

`在籍終了日` を空にします。

## 製品・区分の追加

追加・修正・削除はすべて画面から行えます。**データベースを直接触る必要はありません。**

### 製品を追加する

「製品マスタ」→ ブロック（区分／その他）を選び、製品名と販売開始日を入れる。
追加した製品はその場で受付入力の選択肢に出ます。Excel を配り直す必要はありません。

販売が終わったら `適用終了日` を入れると候補から消えます。過去データは残ります。

### 区分を追加・変更する

「区分マスタ」→ ブロック・区分名・**集計列**・表示順を入れて追加。
`集計列` は必ず確認してください。これがその区分を**集計表のどの列に積むか**を決めます。

| 集計列 | 意味 | 帳票の欄 |
|---|---|---|
| 3 | 申込方法 | 申込 |
| 4 | 抽選結果 | 抽選 |
| 5 | 納付書発送 | 払込用紙 |
| 6 | 商品発送 | 商品発送 |
| 7 | その他 | その他 |
| 8 | 商品交換 | その他（内 交換にも計上） |

`内訳区分` に `返金` と入れた区分は、帳票の「内 返金」に集計されます。

現行 Excel では、この対応が `Sheet2` の 2 行目のセルに埋まっていて、
誰も触れませんでした。ここでは一覧の各行で選び直せます。

### 削除するときの決まり

マスタの一覧には**使用件数**の列があります。ここが 0 でない行は削除できません。

| 使用件数 | できること |
|---|---|
| 0 | そのまま削除できる（間違えて足したものなど） |
| 1 以上 | **削除は拒否される。**「有効」のチェックを外して無効にする |

無効にすると入力候補からは消えますが、**過去の日報・集計表はそのまま残ります**。
消してしまうと過去の帳票からその名前が失われるため、この安全弁を入れています。

担当者だけは扱いが違い、無効化ではなく `在籍終了日` を使ってください
（いつまで在籍していたかが記録として残ります）。

「（製品指定なし）」は製品を伴わない区分のために必要なので、削除できません。

### 業務項目を追加する

「業務項目マスタ」→ 番号と**帳票表示名**を入れる。帳票表示名がそのまま印刷されます。
帳票の欄は表示順で左 8 件 / 右 5 件に割り振られます。

## 月次・年次の点検

| いつ | やること |
|---|---|
| 毎日（確定前） | 入力もれチェック |
| 月末 | 担当者マスタの在籍状況を確認 |
| 月末 | 販売終了した製品に `適用終了日` を入れる |
| 年度末 | バックエンドをコピーして年度別に保管 |
| 随時 | バックエンドの「最適化／修復」 |

### バックアップ

バックエンド `日報集計_be.accdb` を日次でコピーしてください。
共有フォルダのバックアップに含まれていれば別途の作業は不要です。

### 最適化／修復

Access は使い込むとファイルが膨らみます。月 1 回、**誰も使っていない時間に**
バックエンドを開いて「データベース ツール」→「データベースの最適化/修復」を実行してください。

## 現行 Excel との対応表

| 現行の操作 | Access 版 |
|---|---|
| 記入用フォームに入力 | 受付入力画面に入力 |
| 日報集計印刷用フォームの `更新()` | **不要**（入力した時点で反映済み） |
| 印刷用シートに転記されたか確認 | **不要**（同じデータを見ている） |
| 集計表の B2〜B6 に日付を入れる | 集計表画面で期間を指定（「今週」ボタン） |
| 集計表の「転記」ボタン | **不要** |
| 日報と集計表の数値を突き合わせる | **不要**（構造上ずれない） |
| 印刷 | 日報画面の「印刷」 |
| 記入用フォームのクリア | **不要**（日付ごとに別レコード） |
