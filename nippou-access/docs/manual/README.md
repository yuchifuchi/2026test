# マニュアル・手順書

ITに不慣れな方でも読めるよう、**役割ごと**に分けています。ご自分の章だけ読めば足ります。

## 導入するかたへ

**[やさしい導入手順書](やさしい導入手順書.html)**

使えるようにするまでの手順を、1 から 12 の番号で並べたものです。
VBA や IIS を触ったことがない方を想定して書いています。
むずかしい言葉には、そのつど説明をつけました。印刷すると A4 縦 10 ページです。

## 画面写真について

`img/` の画面写真は、実データを入れた評価用の画面（モックアップ）から撮ったものです。
本番の画面と同じ作りです。

画面を変えたときは、次の手順で撮り直せます。

```bash
# モックアップをブラウザで開いて各画面を撮影
python3 - <<'PY'
from playwright.sync_api import sync_playwright
# tools/ の中の撮影スクリプトを参照
PY
```
