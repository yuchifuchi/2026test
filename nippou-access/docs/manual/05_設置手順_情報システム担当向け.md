# 設置手順（情報システム担当者向け）

構成は次のとおりです。

```
[利用者の PC]                    [Web サーバー (IIS)]              [共有フォルダ]
  ブラウザ        ──HTTP──▶   Classic ASP (web/)   ──ACE──▶   日報集計_be.accdb
                                Windows 認証                      (データ本体)
```

利用者の PC に入れるものは**ありません**。Access も不要です。

---

## 1. データベースを共有フォルダに置く

**作る作業はありません。** 納品物の

```
02_データベース_Access\日報集計_be.accdb
```

が、そのまま使えるデータベースです。表・マスタ・つながりまで入っています。
**Access は 1 台も要りません。**

これを共有フォルダに移し、**フルパスを控えてください**（手順 5 で使います）。

```
\\fsx…\share_電話オペレータ\日報\
    日報集計_be.accdb          ← これ 1 つにすべてのデータが入る
    日報集計_be.laccdb         ← 使用中だけできる目印。消さない
```

置き場所の条件は 2 つです。

- **毎日バックアップされるフォルダ**であること
- **Web サーバーから書き込めるフォルダ**であること（手順 4）

> **中に VBA は入っていません。** 開いてもマクロの警告は出ません。
> 保存クエリ（`Q_…`）も入っていません。Web 版は SQL を
> `include\sql.asp` に持っており、Access 側のクエリに依存しないためです。

過去データ（いままでの `集計表（…）.xlsm`）を取り込みたい場合だけ、
Access が 1 台必要です。手順は
[導入手順](../03_導入手順.md) の「任意 A」をご覧ください。

作り直したいときは `02_データベース_Access\任意_作り直すとき\データベースを作る.vbs`
を Access のある PC でダブルクリックします（入力済みのデータは消えます）。

---

## 2. IIS を用意する

### 有効にする機能

- **ASP**（役割と機能 → Web サーバー → アプリケーション開発 → ASP）
- **Windows 認証**（同 → セキュリティ → Windows 認証）

### 追加で入れるもの

- **Microsoft Access Database Engine 2016 Redistributable**

> **アプリケーションプールのビット数を ACE と合わせてください。**
> 64bit の ACE を入れたなら「32 ビット アプリケーションの有効化」は `False` です。
> ここが合っていないと `Provider が見つかりません` というエラーになります。

---

## 3. ファイルを配置する

```
C:\inetpub\wwwroot\nippou\      ← web/ の中身をそのまま
D:\nippou\data\日報集計_be.accdb ← 手順 1 で置いたファイル
```

`web.config` も一緒に置いてください。Windows 認証・既定ページ・
エラー画面・拡張子のブロックがまとめて設定されます。

---

## 4. 権限を与える

`.accdb` を置いた**フォルダ**に、アプリケーションプール ID
（既定は `IIS AppPool\<プール名>`）の**変更権限**を与えます。

> **読み取りだけでは動きません。** ACE がロックファイル `.laccdb` を
> 同じフォルダに作るため、フォルダへの書き込み権限が要ります。

---

## 5. 設定を書き換える

`include/db.asp` の先頭：

```vbscript
Const DB_PATH = "D:\nippou\data\日報集計_be.accdb"
```

`include/auth.asp` の先頭：

```vbscript
' 予備。ふだんは空のままでよい。
Const STAFF_USERS = ""
```

**誰が職員かは、ふだんはマスタ保守の画面で決めます。**
担当者一覧に「ログオン名」の欄があり、そこに Windows のログオン名を入れ、
区分を「職員」にすると、その方に職員用の画面
（日報・帳票印刷・集計表・入力もれ・マスタ保守）が出るようになります。
ファイルを直す必要はありません。

`STAFF_USERS` は、**マスタにまだ誰も登録していないとき**の予備です。
最初の 1 人（マスタ保守を開く人）だけをここに書いておき、
その人がマスタ保守から残りを登録する、という使い方ができます。

**どちらも空のままだと全員が職員扱いです。** 運用開始前に必ず設定してください。

`include/pdf.asp` の先頭（帳票の PDF 印刷）：

```vbscript
Const PDF_ENGINE = "edge"      ' サーバーに Edge があればこのまま
Const PDF_EDGE_EXE = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
Const PDF_WORK_DIR = ""        ' 空なら Windows の一時フォルダを使う
```

- `msedge.exe` の場所が違うときは `PDF_EDGE_EXE` を直します。
- Edge が入っていないサーバーでは、wkhtmltopdf を入れて
  `PDF_ENGINE` を `"wkhtmltopdf"` にしてください。
- 作業用フォルダ（既定は Windows の一時フォルダ）に、
  **アプリケーションプール ID の変更権限**が要ります。
  作った PDF は送った直後に消すので、溜まりません。

## 6. 動作確認

`http://<サーバー名>/nippou/` を開きます。

| 確認すること | 期待する結果 |
|---|---|
| メニューが出る | 職員なら「職員用メニュー」、それ以外は「受付入力メニュー」 |
| 右上の名前 | 自分の Windows ログオン名が出る（職員なら「（職員）」付き） |
| 受付入力 | 担当者の一覧に在籍者が出る |
| 帳票プレビュー →「PDF で印刷する」 | 別タブに PDF が開き、A4 縦 1 枚に収まる |
| PDF の紙面 | 日付や URL（ヘッダー・フッター）が入っていない |
| パート職員のかたのアカウント | 上の帯に「受付入力」「その他業務」だけが並ぶ |
| 同上で `daily.asp` を直接開く | 「この画面は職員のかた専用です」と出る |

## 7. 利用者に配る

デスクトップに `http://<サーバー名>/nippou/` へのショートカットを配布してください。
ITに不慣れな方が多いため、**アドレスを手で打たせない**ことが大事です。

## 運用時の注意

### 文字コード

`.asp` は **UTF-8（BOM なし）** で保存されています。
編集して Shift_JIS で保存し直すと文字化けします。

### SQL の書き方

画面から来た値を文字列連結で SQL に埋めている箇所はありません。
すべて `DbQuery` / `DbExec` のパラメータ経由です。
画面を追加するときも、この 2 つ以外で SQL を組まないでください。

```vbscript
' 良い
DbExec "UPDATE [T_受電] SET [件数]=? WHERE [受電ID]=?", Array(cnt, rowId)

' 駄目
gConn.Execute "UPDATE [T_受電] SET [件数]=" & cnt & " WHERE [受電ID]=" & rowId
```

### バックアップ

`日報集計_be.accdb` を日次でコピーしてください。
共有フォルダのバックアップに含まれていれば別途の作業は不要です。

### 最適化／修復

Access ファイルは使い込むと膨らみます。月 1 回、誰も使っていない時間に
Access で開いて「データベース ツール」→「データベースの最適化/修復」を実行してください。

### 同時利用の目安

Access（ACE）は数十人規模までです。それを超えるなら SQL Server Express への
移行を検討してください。SQL はすべてパラメータ渡しで書いてあるので、
変更が要るのは `include/db.asp` の接続文字列だけです。

## つまずきやすいところ

| 症状 | 原因と対処 |
|---|---|
| `Provider が見つかりません` | ACE 未導入、またはアプリケーションプールのビット数が不一致 |
| `外部データベースを開けません` | `.accdb` を置いたフォルダに書き込み権限が無い |
| 文字化けする | `.asp` を Shift_JIS で保存し直してしまった |
| 右上の名前が「(未認証)」 | 匿名認証が有効なまま。IIS で無効にする |
| 全員が職員用の画面を開ける | `auth.asp` の `STAFF_USERS` が空のまま |
| 「PDF を作れませんでした」と出る | `pdf.asp` の `PDF_EDGE_EXE` の場所ちがい、または作業用フォルダの権限不足。画面に出る枠の中に理由が書いてあります |
| 印刷が 2 枚になる | 印刷倍率が 100% でない、または記述欄が長い |
