# 電話応対日報 集計システム

現行の Excel マクロ一式（記入用フォーム／日報集計印刷用フォーム／集計表）を
**Access に置き換える**ための一式です。同じ Access ファイルを DB として使う
**ASP（イントラ Web）版のモックアップ**も同梱しています。

---

## なぜ作り替えるのか

現行の運用では、次の 3 か所が独立に数を数えていました。

```
記入用フォーム Sheet1 ──┬─→ Sheet2 ──→ 集計表 データシート ──→ SUMIF ──→ 週次の数値
                        └─→ 集計用フォーム(外部リンクで18ファイル合算) ──→ 印刷用シート ──→ 日報の数値
```

経路が 2 本あるため、**日報と集計表がずれても誰にも分かりません**。
実際に次の不具合が起きていました（詳細は [docs/01_現行調査と不具合原因.md](docs/01_現行調査と不具合原因.md)）。

| 現象 | 原因 |
|---|---|
| 特定の人のデータが吸い出せない | 記入用フォームの `Sheet1!B1`（担当者名）が別人のまま。**6 ファイルが該当**し、5 名分が「顧客G」に、1 名分が「髙橋」に合算されていた |
| 同上 | `005三宅記入用フォーム.xlsm` が**フォルダに存在しない**（印刷用フォームは参照しているのに実体なし） |
| 日報と集計表の数値が合わない | `SUMIF` の範囲が行ごとにバラバラ（`$383` / `$935` / `$428`）。データが 383 行を超えると月曜・火曜の合計だけ過少になる |
| 同上 | 集計表が**追記のみでクリアされない**ため、前週のデータが残って二重計上される |
| フォントサイズが勝手に変わる | 記入用フォームの **67 セルに「縮小して全体を表示する」**が設定され、結合セル 76 か所と併用されている |
| 転記された名前が入力画面と違う | `Sheet2` の 3 行目（集計表に書く名前）が入力画面の見出しとズレている（例: 入力画面「宇佐神宮」→ 集計表「イベント関係（造幣局 ＩＮ）」） |

Access 版では、**受付の記録を `T_受電` という 1 つのテーブルにだけ**持ちます。
日報も集計表もそこから作るので、**数値が食い違うこと自体が起こりません**。

## 構成

```
nippou-access/
├─ src/          Access に入れる VBA モジュール (UTF-8。GitHub で読む用)
├─ dist/         同じものを Shift_JIS + CRLF に変換したもの (VBE インポート用)
├─ data/         マスタ初期データ CSV (現行 Excel から機械的に抽出したもの)
├─ tools/        抽出・生成・検査スクリプト (Python)
├─ web/          Access を DB にした ASP サイト (モックアップ)
└─ docs/         調査結果・設計・手順書
```

| 文書 | 内容 |
|---|---|
| [01 現行調査と不具合原因](docs/01_現行調査と不具合原因.md) | 現行マクロの全解析と、不具合の原因の特定 |
| [02 データベース設計](docs/02_データベース設計.md) | テーブル・クエリ・現行 Excel との対応表 |
| [03 導入手順](docs/03_導入手順.md) | Access アプリの作り方（コピペ 3 分） |

## いちばん短い始め方

1. 空の `.accdb` を作って開く
2. `Alt` + `F11` → 挿入 → 標準モジュール
3. `dist/` の 7 ファイルを順に貼り付ける（または「ファイル」→「ファイルのインポート」）
4. `modSetup` の `Setup_All` にカーソルを置いて `F5`

これでテーブル・マスタ・クエリ・画面・帳票が全部できます。
続きは [docs/03_導入手順.md](docs/03_導入手順.md) を参照してください。

## 開発

```bash
# 現行 Excel からマスタを再抽出する
python3 tools/extract_master.py --src <xlsm を置いたフォルダ> --out .

# CSV から VBA モジュールを再生成する
python3 tools/gen_master_vba.py

# VBA を静的チェックする (引用符・行継続・行長・未定義呼び出し)
python3 tools/lint_vba.py

# 配布用 (Shift_JIS) を作り直す
python3 tools/make_dist.py
```
