# 電話応対日報 集計システム

現行の Excel マクロ一式（記入用フォーム 18 本／日報集計印刷用フォーム／集計表）を
置き換えるシステムです。

```
[利用者の PC]                  [Web サーバー (IIS)]            [共有フォルダ]
  ブラウザだけ    ──HTTP──▶  Classic ASP (web/)  ──ACE──▶  日報集計_be.accdb
                              Windows 認証                    (データ本体)
```

- **データベース** … Microsoft Access（`.accdb`）
- **画面** … Classic ASP（イントラネット）
- **利用者の PC に入れるものはありません。** Access も Excel も不要です。

---

## なぜ作り替えるのか

現行の運用では、3 か所が独立に数を数えていました。

```
記入用フォーム ─┬─→ Sheet2 ──→ 集計表 ──SUMIF──→ 週次の数値
                └─→ 集計用フォーム(18ファイル合算) ──→ 印刷用シート ──→ 日報の数値
```

経路が 2 本あるため、**日報と集計表がずれても誰にも分かりません**。
実際に次の不具合が起きていました（詳細は [01 現行調査と不具合原因](docs/01_現行調査と不具合原因.md)）。

| 現象 | 原因 |
|---|---|
| 特定の人のデータが吸い出せない | 記入用フォームの `Sheet1!B1`（担当者名）が別人のまま。**6 ファイル**が該当し、5 名分が「顧客G」に、1 名分が「髙橋」に合算されていた |
| 同上 | `005三宅記入用フォーム.xlsm` が**フォルダに存在しない**（印刷用フォームは参照しているのに実体なし） |
| 日報と集計表の数値が合わない | `SUMIF` の範囲が行ごとにバラバラ（`$383` / `$935` / `$428`）。383 行を超えると月曜・火曜だけ過少になる |
| 同上 | 集計表が**追記のみでクリアされない**ため前週分が二重計上される |
| フォントサイズが勝手に変わる | 記入用フォームの **67 セルに「縮小して全体を表示する」**＋結合セル 76 か所 |
| 転記名が入力画面と違う | `Sheet2` 3 行目の文言が入力画面の見出しとズレている（例: 入力画面「宇佐神宮」→ 集計表「イベント関係（造幣局 ＩＮ）」） |

新システムでは、**受付の記録を `T_受電` という 1 つのテーブルにだけ**持ちます。
日報も集計表もそこから作るので、**数値が食い違うこと自体が起こりません**。

## 導入の流れ

1. **データベースを作る**（Access のある PC で 1 回だけ）
   空の `.accdb` に `dist/` を貼り付けて `Setup_DBOnly` を実行 → 共有フォルダへ
2. **過去データを取り込む**（任意）
   Access の「Excel から取込」で週次の集計表を読み込む
3. **IIS に配置する**
   `web/` を配置し、`db.asp` の `DB_PATH` と `auth.asp` の `ADMIN_USERS` を設定
4. **ショートカットを配る**
   利用者のデスクトップに `http://<サーバー>/nippou/` へのショートカット

くわしくは [設置手順](docs/manual/05_設置手順_情報システム担当向け.md) を参照してください。

## 移行の検算結果

`tools/verify_migration.py` で `集計表（ＶＢＡ版）.xlsm` を実際に流した結果です。

```
成功 306 行 / 引き当て失敗 0 行 / 対象外 65 行（見出し・SUMIF 用の空行）
日別・集計列別の合計は、Excel の生データと全日付で一致
```

取込後に手作業が必要なもの：

| 対象 | 内容 |
|---|---|
| `100 顧客Ｇ` の 17 行 37 件 | 現行の設定ミスで **002堀・004谷口・006国森・009西岡・015鈴木** の 5 名分が混在。判別不能 |
| `015 鈴木` の 29 行 53 件 | データが姓「鈴木」だけで 015 と 018鈴木智 の区別が付かない |
| `005 三宅` | 記入用フォームの実体が無く、そもそも記録が存在しない |

## 既知の制約

- **帳票の業務項目欄は左 8 件・右 5 件の 13 個まで**です。14 個目以降は画面には出ますが紙に載りません。
- Access（ACE）の同時利用は数十人規模までです。超える場合は SQL Server Express への移行を検討してください。
- 記述欄に長文を入れると帳票が 2 枚目に送られます。

## 開発

```bash
python3 tools/extract_master.py --src <xlsm フォルダ> --out .   # マスタ再抽出
python3 tools/gen_master_vba.py                                # VBA 再生成
python3 tools/lint_vba.py                                      # VBA 静的チェック
python3 tools/make_dist.py                                     # 配布用を再生成
python3 tools/verify_migration.py --src <xlsm フォルダ>         # 移行の検算
python3 tools/render_asp_report.py                             # ASP 帳票の印刷検証
```
